## Lab Overview

- **Q1 — Interactive Text Changer:** Changes the welcome message to “Hello there!” when the user clicks **Change Message**.
- **Q2 — Smart Number Validator:** Checks whether the input is a valid number and compares it with 10.
- **Q3 — Dynamic Number Generator:** Creates an ordered list from 1 to 5. The list stays at five items after repeated clicks.

## How to Run

1. **Q1:** Open `q1/index.html` in a browser. Click **Change Message** and check that the text changes from “Welcome to my website!” to “Hello there!”.
2. **Q2:** Open `q2/index.html` in a browser. Try `5`, `10`, `15`, `10.5`, `abc`, and an empty input. Click **Check** after each test.
3. **Q3:** Open `q3/index.html` in a browser. Click **Generate** twice and check that the list still has five items.
